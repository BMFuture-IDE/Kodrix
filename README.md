# Kodrix IDE

> 轻量、开箱即用的 **C++ / Python 集成开发环境**，专为青少年编程学习打造。

## 🧰 内置实用工具

一站式解决青少年从新手打字到练习的全过程：

- **代码演示** — 老师上课演示无需当堂手写代码，提前写好的代码会自动以「打字机」模式逐字输出，边讲边呈现，课堂节奏更从容。
- **代码打字练习** — 针对零基础学员的代码打字训练，帮助熟悉代码符号、关键字与缩进格式，快速练出「代码手感」。
- **计时器** — 内置练习计时与倒计时工具，方便课堂限时训练与自我检测，培养时间管理与专注力。
- **代码评测** — 内置代码评测功能，自动判题并即时反馈结果，让每一次练习都有标准、有进步。
